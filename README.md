# Wexford Smiles

A responsive, accessible redesign for Wexford Smiles Dentistry in Wexford, Pennsylvania.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server.

## Included

- Responsive navigation and a mobile call shortcut
- Practice services, patient welcome, insurance, and financing details
- The listed new-patient, no-insurance special
- Address, phone number, and weekly office hours
- Color palette supplied for the redesign
